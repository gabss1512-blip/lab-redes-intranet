
# 🌐 Laboratório Prático: Redes e Intranet

## 📌 Sobre o Projeto
Montei este laboratório para praticar na mão a estruturação de uma rede local com serviços de intranet. O foco aqui foi configurar a conectividade do zero, ajustar o endereçamento IP e garantir que as rotas e os serviços principais estivessem rodando sem gargalos.

## 🛠️ O que usei
* **Simulação:** Cisco Packet Tracer
* **Protocolos e Serviços:** TCP/IP, DHCP e DNS
* **Validação:** Testes de conectividade com `ping` e `traceroute`

## 🚀 O que tem no repositório
Na pasta raiz você encontra:
* O arquivo do projeto (`.pkt`) para abrir direto no Cisco Packet Tracer.
* As capturas de tela com as configurações e os testes de ping/rotas funcionando.
